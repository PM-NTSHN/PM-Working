02

Vấn đề hiện trạng cần giải quyết

🌐
Attack Surface phình to
Môi trường on-premises + multi-cloud + container + remote khiến kiểm soát tài sản bất khả thi. Hơn 30% tài sản không được biết đến hoặc không được quản lý.
⚠️
Vulnerability Fatigue — Quá tải cảnh báo
Giải pháp cũ dùng CVSS đơn thuần → 51% lỗ hổng bị chấm High/Critical. Đội IT chìm trong cảnh báo, không biết ưu tiên vá gì trước.
🔗
Đứt gãy giữa Security và IT
Security tìm ra lỗ hổng, IT vá bằng SCCM riêng biệt. Rà soát qua bảng tính → MTTR kéo dài → cơ hội cho Ransomware.
03

Tính năng cốt lõi

🔍
Asset Discovery
Tự động tìm 100% tài sản kể cả shadow IT, IoT qua Cloud Agent và Passive Sensor (CAPS). Không cần can thiệp hạ tầng mạng.
📊
TruRisk™ Prioritization
Điểm rủi ro 0–1000 dựa trên mức độ khai thác thực tế (CISA KEV, Ransomware) + tầm quan trọng tài sản. Giảm 85% số lỗ hổng cần xử lý.
🔧
Integrated Patch Management
Tự động khớp lỗ hổng → bản vá. Zero-Touch Patching cho Windows/Linux/Mac + hàng trăm ứng dụng bên thứ 3 (Chrome, Adobe, Zoom) qua Internet, không cần VPN.
⚡
One Platform · One Agent
1 Agent duy nhất, siêu nhẹ (<1% CPU), tự động cập nhật. Loại bỏ hàng loạt tool bảo mật rời rạc, đơn giản hoá vận hành toàn diện.

06

Use Cases thực tế

CASE 01 · Zero-Day Response
⚡ Khắc phục lỗ hổng Zero-Day thần tốc
Khi lỗ hổng ProxyNotShell của Microsoft Exchange nổ ra, khách hàng dùng VMDR tìm ra ngay server dính lỗi. Do chưa có bản vá chính thức, họ dùng tính năng CAR đẩy script cấu hình tạm thời để chặn tấn công, bảo vệ hệ thống ngay lập tức.
CASE 02 · Automation
🤖 Zero-Touch Patching — Vá tự động không cần IT
Quản trị viên thiết lập rule: "Tự động vá Chrome trên toàn công ty trong vòng 24h nếu có bản vá Critical". Mọi thứ diễn ra tự động — IT không cần đụng tay.
CASE 03 · Work From Home
🏠 Vá lỗi máy tính nhân viên WFH — Không cần VPN
Thay vì bắt nhân viên bật VPN gây nghẽn mạng công ty, Qualys Cloud Agent tự động lấy bản vá trực tiếp từ CDN Qualys trên Internet để vá máy tính ở bất cứ đâu.

FAQs — Tư vấn thực chiến

Cấp license dựa trên số lượng Tài sản (Assets/IP Addresses). Chỉ cần hỏi tổng số Server, Workstation, Cloud Instances cần cài Agent hoặc rà quét → nhân với đơn giá VMDR hoặc add-on Patch Management.
Rất đơn giản — Cloud-Native, không cần mua server phần cứng hay cài database nội bộ. Chỉ cần cài 1 Qualys Cloud Agent siêu nhẹ (<1% CPU, có Performance Profile) lên máy trạm/chủ. Giao tiếp an toàn qua port 443 HTTPS.
SCCM mạnh về vá Windows nhưng yếu vá ứng dụng bên thứ 3 (Chrome, Adobe…) và rất khó vá máy ngoài mạng công ty. Qualys PM bổ trợ hoàn hảo: vá ứng dụng bên thứ 3 dễ dàng, tự động ánh xạ lỗ hổng ↔ bản vá, và vá mọi máy có Internet — không cần VPN.
CVSS đánh giá lý thuyết thuần túy. TruRisk (0–1000) đánh giá rủi ro thực tế: lỗ hổng có mã khai thác chưa? Ransomware nào đang dùng không? Server này quan trọng đến đâu? → Giúp bỏ qua "lỗ hổng ảo", tập trung vào 15% tạo ra 85% rủi ro thực sự.
Có. VMDR tích hợp đánh giá cấu hình theo CIS Benchmarks và tạo báo cáo cho PCI-DSS (tích hợp PCI ASV), SOC 2, HIPAA và nhiều tiêu chuẩn khác.
