7 Module
SanerNow CVEM Platform

Đây là điểm khác biệt lớn nhất của SecPod — 7 module hoạt động trên cùng một agent, một console, một database. Không cần tích hợp hay mua riêng:

01
Vulnerability Management (VM)
Phát hiện CVE, missing patch, misconfiguration. Scan dưới 5 phút với 190,000+ SCAP checks. Prioritization theo risk score, severity, exploitability. Tích hợp OWASP Top 10, SANS Top 25.
Real-time scan Risk scoring 190K+ checks Agentless option
02
Patch Management (PM)
Vá lỗi tự động Windows/macOS/Linux/AIX và 550+ 3rd party apps. Patch rollback 1-click. Test group trước khi deploy production. Patch available trong 24h sau release. Zero-touch automation.
550+ apps Rollback Test groups 24h patch feed
03
IT Asset Exposure (AE)
Inventory hardware/software, quản lý license phần mềm, phát hiện shadow IT, ứng dụng hiếm dùng/lỗi thời, blacklist/whitelist apps. Audit-ready reports.
HW/SW inventory Shadow IT License mgmt
04
Compliance Management (CM)
Phát hiện misconfiguration và hardening theo CIS Benchmark, PCI DSS, HIPAA, ISO 27001, NIST. Tự động fix hoặc tạo remediation task. Audit-ready compliance reports.
CIS Benchmark PCI DSS NIST Auto-fix
05
Continuous Posture Anomaly Management (CPAM)
Đây là module độc đáo: liên tục đánh giá 70+ loại anomaly trên 2,000+ data points — phát hiện deviation từ security baseline, process lạ, network anomaly, user behavior bất thường.
70+ anomaly types 2000+ data points Baseline deviation
06
Endpoint Management (EM)
Giám sát endpoint health theo 100+ metrics, remote scripting (Windows/Linux/macOS/AIX), application/device control, system hardening, performance monitoring, EDR-lite capabilities.
100+ metrics Remote scripting App control v6.5 feature
07
Software Deployment Management (SDM)
Triển khai phần mềm tập trung đến endpoint không cần VPN. Remote software push, uninstall, custom scripts. Hữu ích cho tổ chức có nhiều remote worker.
No VPN needed Remote deploy Cloud-based
💡 Tip khi demo: Nhấn mạnh rằng 1 agent duy nhất thực hiện TẤT CẢ 7 tác vụ trên. Khách hàng hiện tại thường dùng 3–4 tool riêng lẻ (VM scanner + Patch tool + Asset tool + Compliance checker) với nhiều agent khác nhau — tốn tài nguyên, khó quản lý, chi phí cao hơn.

Kiến Trúc &
Cách Hoạt Động

Các thành phần hệ thống
☁️Saner Cloud Platform (SaaS): Management console hosted bởi SecPod. Xử lý scan data, correlation, analytics, reporting. Browser-based, không cài gì trên phía khách hàng.
🖥️Saner Web Console: Giao diện quản trị trên browser — dashboard, policies, scan schedule, reporting, remediation workflow.
📦Saner Agent: Agent nhẹ cài trên endpoint (Windows/Linux/macOS/AIX). Kết nối HTTPS outbound port 443 về SaaS Platform — không cần mở inbound port. Thực hiện scan, thu thập data, apply patch.
🌐Network Scanner: Có thể chỉ định 1 agent làm network scanner để quét các thiết bị không có agent (router, switch, printer, IoT) trong cùng subnet — agentless scan qua agent proxy.
Luồng hoạt động cơ bản
1️⃣Agent khởi động, kết nối Saner Platform qua HTTPS port 443
2️⃣Agent nhận policy scan từ Console, thực thi scan local trong dưới 5 phút
3️⃣Kết quả scan được gửi về Platform, engine phân tích và so sánh với SCAP feed
4️⃣Vulnerability được ưu tiên theo risk score, hiển thị trên console dashboard
5️⃣Tự động tạo remediation job (patch), hoặc tạo ticket qua ServiceNow/Freshservice
6️⃣Patch được deploy, agent xác nhận kết quả, cập nhật vulnerability status
⚠️ Điểm cần lưu ý khi tư vấn: SanerNow mặc định là cloud SaaS — console và data lưu trên server của SecPod. Với khách hàng nhà nước/quân đội tại Việt Nam có yêu cầu data sovereignty, cần hỏi SecPod về on-premise deployment option và xác nhận khả năng lưu trữ dữ liệu trong nước. Đây là điểm mà Tenable Nessus Pro có lợi thế hơn (fully offline, không gửi data ra ngoài).
🔌 Network requirements: Agent chỉ cần kết nối outbound HTTPS port 443 đến Saner Cloud Platform. Không cần mở inbound port — phù hợp với môi trường có firewall nghiêm ngặt. Với on-premise, tất cả traffic trong mạng nội bộ.

FAQ Kỹ Thuật
Thường Gặp Khi Demo/PoC

Q
SanerNow có thể scan được thiết bị mạng (router, switch, firewall) không, hay chỉ quét endpoint có agent?
Kỹ thuật +

Có. SanerNow hỗ trợ cả hai chế độ:

  • Agent-based: Endpoint có cài Saner Agent — Windows, Linux, macOS, AIX. Chính xác nhất.
  • Network scan (agentless): Chỉ định một endpoint đã có agent làm "Network Scanner". Agent này sẽ thực hiện authenticated hoặc unauthenticated scan các thiết bị khác trong subnet — bao gồm router, switch, printer, IoT device. Kỹ thuật tương tự Nessus nhưng qua agent proxy.

Để thực hiện network agentless scan: vào Console → Device Management → chọn agent → "Designate as Network Scanner" → cấu hình IP range cần quét.

Lưu ý: Agentless network scan của SanerNow không đồng nghĩa với "không cần agent nào trong mạng đó" — vẫn cần ít nhất 1 agent làm gateway scanner. Tenable Nessus Pro hoàn toàn agentless không cần điều kiện đó.
Q
Saner Agent nặng bao nhiêu? Có ảnh hưởng hiệu năng endpoint không?
Kỹ thuật +

Agent SecPod được thiết kế nhẹ và đa năng. Đặc điểm:

  • Kích thước agent nhỏ, chiếm RAM thấp khi idle
  • Scan xảy ra cực nhanh (<5 phút) nên spike CPU chỉ trong thời gian ngắn
  • Agent thực hiện scan local — không tốn bandwidth mạng trong quá trình scan
  • Chỉ gửi kết quả (dạng structured data nhỏ) lên cloud sau khi scan xong
  • Có thể cấu hình scan windows (giờ thấp điểm) để tránh ảnh hưởng giờ làm việc

Nhiều khách hàng trong review Gartner và AWS Marketplace ghi nhận agent "lightweight" và không gây vấn đề hiệu năng đáng kể.

Q
Làm sao deploy agent hàng loạt? Có thể dùng GPO / SCCM / Ansible không?
Kỹ thuật +

SecPod hỗ trợ nhiều phương thức deploy agent:

  • Email invite: Gửi link download agent qua email đến user
  • Command line: Silent install qua command line — phù hợp với script deployment
  • Saner Offline Deployer Tool: Tool của SecPod để deploy/uninstall agent hàng loạt
  • GPO (Group Policy): Deploy qua Windows GPO trong AD domain
  • SCCM/Intune: Có thể package agent installer cho deployment qua SCCM/Intune
  • Ansible/Chef/Puppet: Có thể tích hợp thông qua script installation
Điểm cần cải thiện: Auto agent deployment qua AD discovery (tự động phát hiện machine trong AD và push agent) chưa được tích hợp native — đây là feedback phổ biến từ khách hàng Gartner. Cần check version mới nhất (6.5+) xem đã cải thiện chưa.
Q
SanerNow có tích hợp với SIEM và ticketing system không?
Kỹ thuật +
  • ServiceNow: Tích hợp native — tự động tạo incident/change ticket khi phát hiện vulnerability nghiêm trọng
  • Freshservice: Tích hợp native (ra mắt trong release 6.5)
  • REST API: Đầy đủ REST API để tích hợp với bất kỳ SIEM/ITSM nào
  • Email alerts: Cấu hình gửi email khi phát hiện CVE critical mới
  • Syslog: Forward events qua syslog đến SIEM (Splunk, IBM QRadar, ArcSight...)
So với Rapid7: Rapid7 InsightVM có 500+ native integrations — vượt trội. SecPod có ít pre-built integrations hơn nhưng REST API đầy đủ bù đắp được. Nhấn mạnh điều này khi khách hàng hỏi.
Q
Scan có thể thực hiện không có internet không? Có hỗ trợ air-gap environment không?
Kỹ thuật +

Đây là câu hỏi quan trọng, đặc biệt với khách hàng chính phủ/quân đội:

  • Cloud SaaS (mặc định): Agent cần kết nối internet để giao tiếp với Saner Platform. Không phù hợp air-gap.
  • On-Premise deployment: SecPod có thể cung cấp on-premise server. Cần liên hệ SecPod để xác nhận tính năng và điều kiện. Trong trường hợp này, dữ liệu và communication đều nội bộ.
⚠️ Khi khách hàng yêu cầu air-gap: Cần xác nhận rõ với SecPod về on-premise option trước khi cam kết. Tenable Nessus Pro là lựa chọn tốt hơn cho air-gap hoàn toàn — cài trên laptop, offline plugin update, zero cloud dependency.
Q
SanerNow cập nhật signature/vulnerability database bao lâu một lần?
Kỹ thuật +
  • SCAP feed cập nhật hàng ngày với các CVE mới từ NVD, MITRE, và SecPod Labs
  • Patch repository cập nhật trong vòng 24 giờ sau khi vendor release patch mới
  • SecPod Labs theo dõi và broadcast email alerts khi có critical CVE mới — không cần chờ scan định kỳ
  • Agent tự động nhận feed mới khi kết nối về Platform — không cần can thiệp thủ công
Q
Có thể xem báo cáo dạng PDF/Excel không? Báo cáo có tùy chỉnh được không?
Kỹ thuật +
  • Export PDF — dành cho báo cáo nộp lãnh đạo, kiểm toán
  • Export CSV/Excel — dữ liệu chi tiết vulnerability, asset, patch status
  • Custom reports: Có thể tạo template báo cáo tùy chỉnh
  • Scheduled reports: Tự động gửi email report theo lịch (tuần/tháng)
  • Dashboard: Dashboard trực quan, role-based — CISO thấy summary, admin thấy chi tiết
Điểm yếu cần thừa nhận: Nhiều user phản hồi rằng report của SanerNow "đủ dùng nhưng không đẹp" — không fancy như Rapid7 LiveDashboard. Nếu khách hàng cần executive reporting ấn tượng thì đây là điểm kém hơn.

Vấn Đề Khách Hàng Hay Quan Tâm

Q
Tại sao nên chọn SecPod thay vì Tenable hay Qualys mà nhiều người biết hơn?
Business +

Câu trả lời tốt nhất tập trung vào 3 lý do thực tế:

  • 1. All-in-one TCO thấp hơn: Tenable Nessus Pro chỉ là vulnerability scanner — muốn patch management phải mua thêm Tenable Patch Management (add-on riêng). Qualys tương tự — patch license riêng. SecPod bao gồm VM + Patch + Compliance + Asset trong một license duy nhất. Tiết kiệm 40–60% so với mua rời.
  • 2. Nhanh hơn đáng kể: Scan dưới 5 phút vs Tenable 30–60 phút và Qualys còn chậm hơn. Với continuous monitoring, tốc độ là yếu tố quan trọng.
  • 3. End-to-end automation: Phát hiện vulnerability → tự động patch trong cùng một console — không cần chuyển tool, không cần correlation thủ công.

Tenable và Qualys phù hợp hơn nếu khách hàng cần: air-gap hoàn toàn, OT/SCADA coverage, hoặc đã đầu tư lớn vào ecosystem của họ.

1 license bao gồm những gì? Có phải mua riêng từng module không?
License +

SecPod có mô hình licensing linh hoạt theo module:

  • Toàn bộ platform (tất cả 7 modules): Mua một gói — VM + Patch + Asset + Compliance + CPAM + EM + SDM
  • Chọn module riêng lẻ: Ví dụ chỉ mua VM + PM (phổ biến nhất) — giá thấp hơn gói đầy đủ
  • 1 agent cho tất cả: Dù mua module nào, chỉ cài 1 Saner Agent per endpoint. Khi nâng cấp/thêm module, chỉ cần activate trên console, không cài lại agent.
Gợi ý cho khách hàng mới: Bắt đầu với VM + PM — đây là combo thường gặp nhất, giải quyết 80% nhu cầu. Sau 6–12 tháng mở rộng thêm Compliance hoặc CPAM khi tổ chức đã quen.

Phản hồi cần phân tầng theo loại khách hàng:

  • Nếu khách hàng là doanh nghiệp tư nhân: Clarify rằng dữ liệu scan (CVE list, IP, hostname) không phải "dữ liệu cá nhân" theo NĐ 13/2023. Tuy nhiên đối với hạ tầng quan trọng, cần thận trọng.
  • Nếu là nhà nước/quân đội: Đề xuất on-premise deployment option của SecPod. Xác nhận với SecPod về khả năng deploy server tại datacenter khách hàng.
  • Nếu on-prem không khả thi: Thành thật giới thiệu Tenable Nessus Pro như lựa chọn offline hoàn toàn — đây là đúng đắn hơn về mặt tư vấn, giúp xây dựng uy tín.
"SecPod cần agent trên mỗi máy. Chúng tôi không muốn cài thêm gì trên endpoint."
  • 1 agent thay 3–4 tools khác: Nếu hiện tại khách hàng đang chạy AV agent + Patch agent + Asset agent riêng lẻ, thì cài 1 Saner agent thực ra giảm số lượng agent trên endpoint
  • Network scan option: Thiết bị không thể cài agent (router, switch, printer, legacy server) có thể được scan qua Network Scanner mode — agentless từ góc độ thiết bị đó
  • Nếu agentless tuyệt đối là yêu cầu: Tenable Nessus Pro là lựa chọn phù hợp hơn
"190,000 checks của SanerNow ít hơn 227,000 plugins của Tenable."
  • Đây là so sánh về số lượng — không phản ánh đầy đủ chất lượng và relevance
  • SecPod là OVAL contributor — OVAL là chuẩn mở quốc tế mà Tenable cũng xây dựng plugins dựa trên đó. Chất lượng check của SanerNow có nền tảng kỹ thuật vững
  • Cả hai đều phủ hầu hết CVE quan trọng — trong thực tế, chênh lệch 37,000 checks chủ yếu là các CVE ít phổ biến hoặc legacy
  • Đề xuất: "Trong POC, so sánh kết quả scan cùng một môi trường giữa hai tool — số lượng CVE quan trọng phát hiện được quan trọng hơn tổng số checks"
"Patch Management của SecPod có thực sự an toàn? Lỡ patch sai thì sao?"
  • Test Groups: Tạo nhóm test (5–10 máy) để kiểm tra patch trước khi roll out toàn bộ
  • Patch Rollback 1-click: Nếu patch gây vấn đề, rollback về version ổn định trước đó ngay lập tức — zero downtime
  • Patch verification: SecPod test và verify tất cả patch trước khi đưa vào repository — patch available sau 24h kể từ khi vendor release và đã qua kiểm tra
  • Scheduled maintenance window: Cấu hình patch chỉ deploy trong giờ thấp điểm (ví dụ 2–4am)
  • Incremental rollout: Có thể cấu hình % endpoint nhận patch mỗi đợt
Câu trả lời ngắn gọn: "Test group + patch rollback 1-click là safety net. Không có gì là 100% rủi ro bằng không, nhưng SanerNow cho bạn công cụ để rollback trong vài giây nếu có vấn đề."

  • Tập trung vào gap hiện tại: "Sau khi Tenable tìm ra vulnerability, bạn vá lỗi như thế nào hiện nay? Có tool tích hợp chưa?" → Nếu chưa có → đây là pain point SecPod giải quyết
  • ROI argument: "Thêm SecPod PM thay vì mua Tenable Patch Management add-on riêng — so sánh giá hai option này"
  • Nếu khách hàng quyết tâm giữ Tenable, chấp nhận và duy trì quan hệ — tương lai họ có thể review lại
