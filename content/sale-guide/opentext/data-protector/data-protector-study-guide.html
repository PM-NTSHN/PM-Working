Kiến trúc Data Protector

Kiến trúc đa tầng, thống nhất, linh hoạt — có thể scale từ vài server đến hàng nghìn server trên nhiều site.

Thành phần cốt lõi

Cell Manager

  • Não bộ của hệ thống Data Protector
  • Quản lý toàn bộ backup policies, catalog, scheduling
  • Cài đặt trên Windows, Linux, hoặc HP-UX
  • Một Cell Manager quản lý được toàn bộ "cell" (tập hợp các client)

Manager of Managers (MoM)

  • Quản lý tập trung nhiều Cell Manager từ một console
  • Phù hợp môi trường doanh nghiệp lớn, multi-site
  • Centralized licensing trong môi trường MoM

Media Agent (MA) & Disk Agent (DA)

  • Media Agent: chịu trách nhiệm di chuyển dữ liệu đến backup device (tape, disk, cloud)
  • Disk Agent: agent cài trên client để backup file system
  • Hỗ trợ parallel và multiplexed data streams — backup nhiều nguồn đồng thời

Internal Database (IDB)

  • Catalog lưu trữ toàn bộ metadata về backup sessions, media, objects
  • Là nền tảng cho tính năng tìm kiếm, reporting, restore
  • Tự động backup IDB để đảm bảo continuity của hệ thống backup

Mô hình triển khai

  • On-premises: Cell Manager + Media Server + Agents tại datacenter
  • Remote/Branch site: Installation Server đẩy agent, không cần admin local
  • Hybrid Cloud: backup target cloud (Azure, AWS S3) tích hợp native
  • Virtual: agentless backup VMware/Hyper-V không cần cài agent trong VM

GUI & Quản lý

  • Giao diện đồ họa (GUI) web-based + desktop client
  • CLI (Command Line Interface) cho scripting và automation
  • REST API cho tích hợp vào portal/ITSM của khách hàng
  • Nhiều admin có thể cùng quản lý từ nhiều console khác nhau

💡 Key selling point: Một console duy nhất quản lý toàn bộ môi trường — physical, virtual, cloud — giảm tải đáng kể cho đội vận hành IT.

Tính năng chính

14 tính năng cốt lõi tạo nên sức mạnh của Data Protector.

1. Standardized Protection

  • Bảo vệ tập trung qua môi trường physical, virtual, cloud từ một nền tảng
  • Hỗ trợ đa dạng OS: Windows, Linux, UNIX, HP-UX, AIX, Solaris
  • Support matrix rộng nhất: disk, tape, cloud làm backup target
  • Từ datacenter trung tâm đến remote site đều quản lý được

2. Application-Consistent Recovery

  • Agent tích hợp sâu với ứng dụng: biết trạng thái application khi backup
  • Đảm bảo backup ở trạng thái consistent — không bị corrupt khi restore
  • Automated transaction log backup & truncation
  • Point-in-time recovery: phục hồi đến đúng thời điểm trước sự cố
  • Granular Recovery Extension (GRE): phục hồi từng item riêng lẻ

3. Advanced Virtual Server Protection

  • Native agentless backup VMware vSphere và Microsoft Hyper-V
  • Policy inheritance: VM mới tự động áp dụng backup policy
  • Hardware-assisted backup: offload khỏi hypervisor layer
  • VM Power On: khởi động VM trực tiếp từ backup image
  • Live Migrate: khởi động từ backup, đồng thời restore về đích
  • Cached GRE: phục hồi file từ backup image mà không cần restore VM

4. Data Protector Deduplication (DPD)

  • Software dedup tích hợp, không cần appliance riêng
  • Dedup cả source side và target side
  • Data vẫn deduplicated khi truyền qua mạng → tiết kiệm bandwidth
  • Scale đến hơn 1 PB source data
  • Hỗ trợ Linux và Windows, nhiều folder/mount points

5. High-Performance Backup

  • Backup đến hàng trăm device đồng thời
  • Parallel data streams — nhiều luồng dữ liệu song song
  • Multiplexed backup — ghi nhiều nguồn vào một device
  • Synthetic backup: tạo full backup từ existing incremental
  • Disk staging: dữ liệu lên disk trước, sau chuyển sang tape/cloud

6. Predictive Analytics & Orchestration

  • Dashboard thời gian thực về KPI backup/recovery
  • Advanced integrated reporting (Premium): client stats, licensing, sessions
  • Business Value Dashboard (BVD): truy cập từ bất kỳ thiết bị nào
  • Phân tích dự đoán xung đột lịch backup, contention tài nguyên
  • Operations Orchestration (OO): tạo workflow tự động hóa quy trình
  • Rapid root-cause analysis trước khi sự cố leo thang

7. REST API Access

  • Authentication & authorization layer đầy đủ
  • Tích hợp Data Protector vào service portal/ITSM của khách hàng
  • Self-service restore: File System, SQL, SAP, Oracle, VMware, Hyper-V
  • Script hóa mọi tương tác với Data Protector

8. Data Security

  • Mã hóa AES-256 (software-based): encrypt trước khi truyền qua mạng
  • Drive-based encryption: tận dụng firmware của backup drive
  • Quản lý encryption key: expire, reactivate, export, import, delete

  • 0 lỗi khi verify backup

Bảo mật & Ransomware Protection

Mô hình bảo mật đa lớp — từ truyền thông, mã hóa dữ liệu đến bảo vệ chống ransomware toàn diện.

Mô hình bảo mật truyền thông

  • TLS 1.2: tất cả communication giữa các Data Protector components
  • Secure Peering: Cell Manager ↔ Installation Server qua TLS channel riêng
  • Trust Verification: xác thực quan hệ Cell Manager / Installation Server
  • SMB Signing: khi push install agent trên Windows (data integrity)
  • SSH Protocol: khi push install agent trên Linux/Unix
  • Certificate Pinning: self-signed cert với pinning thay vì root CA
  • Common Criteria Certified: chứng nhận quốc tế về bảo mật phần mềm

Mã hóa dữ liệu

  • AES-256 Software Encryption: mã hóa TRƯỚC KHI truyền qua mạng và ghi ra media
  • Drive-based Encryption: tận dụng firmware của backup drive hardware
  • Quản lý key: expire, reactivate, export, import, delete qua CLI/GUI
  • Phát hiện được object nào đã mã hóa qua GUI hoặc CLI

Chống Ransomware — 5 lớp bảo vệ

1

Linux OS deployment

Cell Manager trên Linux ít bị ảnh hưởng bởi ransomware hơn Windows. Ransomware thường nhắm vào Windows trước.

2

Data Immutability & WORM

Backup data ghi WORM (Write Once Read Many) — không thể sửa hay xóa sau khi ghi. Tape tự nhiên là immutable.

3

Air Gapping

Tape được export khỏi library và lưu offline. Ransomware không thể tiếp cận dữ liệu không có kết nối mạng.

4

Malware Check trước Backup

Tích hợp Webroot để scan malware trước khi backup. Có thể abort backup nếu phát hiện ransomware — không backup dữ liệu đã nhiễm.

5

Backup Verification & Bare Metal DR

Tự động verify backup integrity. EADR nhúng sẵn — phục hồi toàn bộ hệ thống không tốn thêm chi phí.

Tape — Air Gap tuyệt đối

  • Tape không bao giờ expose file-system-like access → malware không đọc được
  • Data trên tape: interleaved, encrypted, chỉ backup app mới đọc được
  • Export tape ra khỏi library → lưu vault vật lý → air gap hoàn toàn
  • WORM tape: không thể modify ở hardware level
  • Ship tape sang location khác: không qua WAN → không bị intercept

🛡️ Thông điệp bán hàng: "Khi ransomware tấn công, câu hỏi không phải là CÓ bị tấn công không — mà là BAO LÂU để phục hồi. Data Protector đảm bảo bạn luôn có clean copy để restore."

Granular Recovery Extension (GRE)

Phục hồi từng item riêng lẻ mà không cần restore toàn bộ database — tính năng độc đáo xử lý 80% yêu cầu recovery thường ngày.

💡 Analogy hay: "Thay vì restore cả tòa nhà để tìm lại 1 chiếc ghế, GRE cho phép bạn đi thẳng vào đúng phòng và lấy đúng chiếc ghế đó."

GRE for Exchange Server

Phục hồi item level trong Exchange mailbox:

Emails Contacts Calendar items Tasks Notes
  • Restore DB về temporary location → tạo Recovery Database (RDB)
  • Mount RDB vào cache → duyệt và tìm kiếm item
  • Restore về mailbox gốc, mailbox khác, hoặc filesystem
  • Production không bị gián đoạn trong suốt quá trình

GRE for SharePoint

Document Folder List Library Calendar item Entire Site + subsites Metadata & Workflow
  • Tích hợp vào SharePoint Central Administration UI
  • Site Collection Admin tự restore — không cần IT Admin
  • Tìm kiếm nâng cao theo author, date, document type
  • Restore về different farm, different site, hoặc filesystem
  • Phục hồi cả site đã xóa kể cả khi recycle bin đã trống

GRE for VMware vSphere

  • Plugin tích hợp HTML5 vCenter UI

  • Standard GRE: restore về Mount Proxy → copy file về đích

Lưu ý: Cached GRE yêu cầu HPE StoreOnce hoặc Dell EMC Data Domain làm backup target.

Disaster Recovery & Information Retention

Enhanced Automated DR (EADR)

  • Bare-metal recovery: phục hồi hoàn toàn từ/đến physical và virtual systems
  • Backup cả OS files, drivers, boot process — không chỉ application data
  • Kích hoạt bằng một checkbox trong Data Protector GUI
  • Tạo DR image từ bất kỳ existing backup set — không cần backup đặc biệt
  • Không tốn thêm chi phí license — có sẵn trong Data Protector
  • Phục hồi từ bất kỳ backup set nào (full, incremental, object copy)

Instant Recovery (ZDB)

  • Snapshot lưu ngay trên storage array → restore point tại chỗ
  • RTO gần bằng 0 cho critical applications
  • Storage array là first point of recovery
  • Tích hợp HPE storage và NetApp SnapMirror

Licensing

3 mô hình license, mỗi mô hình phù hợp với nhu cầu khác nhau. Hiểu rõ để tư vấn đúng.

3 mô hình licensing

Express — Socket-based License (SBL)

  • Tính theo số CPU socket của hypervisor host (ESX, Hyper-V)
  • Chỉ dành cho môi trường ảo hóa
  • Mọi tính năng liên quan VM đều included (GRE, Power On, Live Migrate)
  • Quản lý socket qua GUI, không dùng CLI
  • Upgrade lên Premium chỉ cần đổi license key
KHUYẾN NGHỊ

Premium — Capacity-based License (CBL)

  • Tính theo TB front-end data được bảo vệ (1 TB = 1024 GB)
  • Bảo vệ toàn bộ môi trường: physical + virtual + database + cloud
  • Multiple backup copies không tốn thêm license
  • Pay-as-you-grow: mua thêm TB khi dữ liệu tăng
  • License có thể transfer sang server/storage/app mới
  • Bao gồm unlimited use of enterprise features
  • Subscription license cũng có (OPEX model)

→ Tối ưu cho tổ chức cần bảo vệ môi trường hybrid đầy đủ

Feature-based License (Traditional)

  • License từng tính năng riêng lẻ: cell manager, tape drives, libraries, extensions
  • Chi phí vào thấp hơn, nhưng phức tạp hơn khi tính toán
  • Mỗi Cell Manager cần license riêng
  • Phù hợp môi trường ổn định, ít thay đổi

Q&A — Câu hỏi thường gặp từ khách hàng

Chuẩn bị sẵn câu trả lời cho các objection phổ biến nhất.

❓ "Chúng tôi đang dùng Veeam, sao phải chuyển?"

  • Veeam mạnh với VMware thuần túy; Data Protector mạnh hơn với môi trường hybrid phức tạp: physical server, SAP HANA, Oracle, AS/400
  • DP có native integration sâu hơn với SAP, Oracle — critical cho enterprise
  • Support matrix DP rộng hơn đáng kể (200+ chứng nhận 3rd party)
  • Nếu khách hàng chỉ dùng VMware → Express là lựa chọn tốt với giá cạnh tranh

❓ "Giá của Data Protector thế nào?"

  • Express: theo socket — rõ ràng, dễ tính cho môi trường VM
  • Premium: theo TB front-end — pay-as-you-grow, không surprise cost
  • Multiple backup copies không tốn thêm (Premium) — value rõ ràng
  • TCO thấp hơn vì 1 giải pháp thay nhiều tool → ít đào tạo, ít licensing khác nhau

❓ "Chúng tôi đã có M365, sao cần backup thêm?"

  • Microsoft chỉ giữ data 30-90 ngày trong recycle bin — không đủ cho compliance
  • M365 không bảo vệ khỏi: accidental deletion, malicious insider, ransomware
  • Không có granular restore (item level) trong M365 native
  • DP4CW backup Exchange Online, SharePoint, Teams, OneDrive đầy đủ, lâu dài

❓ "Triển khai có phức tạp không?"

  • Cell Manager cài trên Windows/Linux — standard server, không cần hardware đặc biệt
  • Agent push tự động từ Installation Server — không cần đến từng server cài tay
  • EADR kích hoạt bằng một checkbox trong GUI
  • 90 ngày trial để test trước khi cam kết

❓ "Nếu ransomware tấn công, phục hồi mất bao lâu?"

  • Phụ thuộc vào chiến lược backup đã thiết lập trước
  • Instant Recovery từ snapshot: phục hồi critical app trong phút
  • EADR bare-metal: phục hồi toàn bộ server trong vài giờ
  • Có thể ưu tiên hệ thống nào phục hồi trước (prioritization)
  • Data Protector giảm RTO trung bình 18% theo số liệu thực tế

❓ "Cloud đã backup rồi cần gì backup nữa?"

  • Cloud provider SLA về data: thường không cam kết recovery từ user error
  • Cloud không tự bảo vệ khỏi: ransomware (sync ngay vào cloud), xóa nhầm
  • Egress cost khi restore lớn từ cloud có thể rất đắt nếu không có giải pháp đúng
  • Compliance: một số ngành yêu cầu data copy offline / air-gapped

❓ "Chúng tôi đang dùng SAP HANA, bảo vệ thế nào?"

  • Native SAP HANA integration — hiểu cấu trúc dữ liệu HANA
  • Backup theo HANA internal schedule, tích hợp HANA Studio
  • Log backup liên tục → point-in-time recovery đến gần thời điểm sự cố
  • ZDB với HPE storage: snapshot HANA không downtime
