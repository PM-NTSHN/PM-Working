Pain Points cần giải quyết

🚫 Anti-Virus truyền thống mù quáng với Zero-day

AV và sandbox cổ điển nhận diện bằng chữ ký hoặc hành vi đã biết — thường xuyên bỏ lọt mã độc tinh vi và các cuộc tấn công chưa từng thấy.

📎 Mã độc ẩn trong file công việc hàng ngày

Tội phạm mạng nhúng payload vào Word, Excel, PDF rồi tải lên qua Web Portal, Email, USB — đây là con đường phổ biến nhất để xâm nhập hệ thống.

🏭 Môi trường OT/ICS cách ly (Air-gapped) không an toàn

Mạng cô lập vẫn bị xuyên thủng bởi nhà thầu, kỹ sư mang USB/thiết bị ngoại vi chứa mã độc cắm trực tiếp vào hệ thống SCADA.

📋 Tuân thủ GDPR, HIPAA, PCI-DSS ngày càng nghiêm ngặt

Rò rỉ PII, số thẻ tín dụng, hồ sơ y tế dẫn đến phạt nặng và mất uy tín. Cần kiểm soát tự động, không phụ thuộc con người.

Thực tế triển khai

4 Use Case dễ chốt sale nhất

1

🌐 Web Portal Security

Tích hợp qua REST API. Người dùng upload hồ sơ (PDF, Word, Ảnh) lên cổng dịch vụ công/ngân hàng → MetaDefender quét + làm sạch ngay lập tức trước khi lưu vào server.

2

🔗 Network Perimeter

Tích hợp qua ICAP với F5 BIG-IP, NGINX, Fortinet WAF. Mọi file qua tường lửa/LB đều bị chặn, gửi sang OPSWAT làm sạch rồi mới qua.

3

💾 Kiosk & USB — Mạng Air-gapped

Nhà máy điện, OT: kỹ sư cắm USB vào trạm kiểm tra (Kiosk) → OPSWAT quét, làm sạch, loại bỏ mã độc → mới cho chuyển file vào hệ thống điều khiển.

4

🗄️ Storage Security

Quét định kỳ kho dữ liệu dùng chung (Dell Isilon, Nutanix, AWS S3) phát hiện mã độc ẩn náu và tự động che mờ tài liệu nhạy cảm.

FAQ — Phản bác từ khách hàng

Q1: Cơ chế tính license như thế nào?
+
Mua theo dạng Annual Subscription (BYOL). Cấu trúc giá phụ thuộc 2 yếu tố: (1) Tính năng cần active — Deep CDR, DLP, Sandbox mua kèm theo nhu cầu và (2) Gói Engine quét (8, 12, 16, 20 hoặc MAX 30+ engine). Không giới hạn số lượng file quét hay số lần quét đồng thời.
Q2: "Chúng tôi đã có Firewall và AV, mua thêm OPSWAT làm gì?"
+
Firewall chặn ở mức mạng. Endpoint AV nhận diện bằng chữ ký. Cả hai đều không thể xử lý File-borne malware nhúng trong Word/Excel/PDF. MetaDefender không cố "bắt" mã độc — nó trực tiếp phân rã file, vứt bỏ mọi thành phần rủi ro (macro, script), xây lại file sạch. Đây là phòng ngừa chủ động Zero Trust mà các giải pháp cũ không có.
Q3: Mạng nội bộ cách ly (Air-gapped) có dùng được không?
+
Hoàn toàn được và cực kỳ phù hợp. MetaDefender Core được thiết kế để deploy On-Premises. Với Air-gapped, tải file cập nhật engine thủ công từ máy có mạng đưa vào nội bộ hàng ngày. Hoặc dùng giải pháp Data Diode/NetWall của OPSWAT để đồng bộ một chiều.
Q4: Triển khai có phức tạp, ảnh hưởng hệ thống đang chạy không?
+
Không cần đập kiến trúc cũ. Tích hợp API nhanh vào Web Portal. Nếu dùng F5, Citrix, NGINX — OPSWAT có máy chủ ICAP tích hợp dạng "Plug-and-Play" trong chưa đầy 10 phút, không thay đổi routing. Hỗ trợ Container/Docker và Cloud (AWS, Azure).
Q5: Sizing / BOM phần cứng cần chuẩn bị gì?
+
Hỗ trợ Windows và Linux. Xem bảng BOM ở trên. Lưu ý: nếu bật thêm Deep CDR, DLP hoặc Sandbox thì cộng thêm tối thiểu 4 CPU Cores + 8GB RAM so với cấu hình gói engine chọn.
